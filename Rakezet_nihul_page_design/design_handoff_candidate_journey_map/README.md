# Handoff: מפת מסע מועמד — מסך רכזת (Techcareerly)

## Overview
מסך המוצג לרכזת כשהיא לוחצת על שם מועמד ברשימת המשתתפים: מפת מסע ויזואלית (serpentine) של מועמד בודד — 6 שלבים, 12 תחנות נגזרות-אירועים — עם כרטיס פרסונה למעלה, פאנל פירוט-תחנה בלחיצה, וציר ביקורים למטה. המסך משרת **התערבות, לא הערכה**: אין ציונים, אין השוואה בין מועמדים. השאלה שהוא עונה עליה: "איפה האדם עכשיו, איפה נתקע, ומה הפעולה שלי?"

## About the Design Files
הקבצים בחבילה הם **רפרנס עיצובי שנבנה ב-HTML** — אב-טיפוס שמדגים מראה והתנהגות, לא קוד פרודקשן להעתקה. המשימה: **לממש מחדש את המסך בסביבת הקוד הקיימת** (React/Vue/וכו') לפי הדפוסים והספריות של הקודבייס. אם אין סביבה קיימת — לבחור פריימוורק מתאים ולממש שם.

פתיחת האב-טיפוס: `Candidate Journey Map.dc.html` נפתח ישירות בדפדפן (דורש את `support.js` באותה תיקייה). התבנית בין תגי `<x-dc>`, הלוגיקה והדאטה במחלקת `Component` בתחתית הקובץ.

## Fidelity
**High-fidelity.** צבעים, טיפוגרפיה, ריווחים ומצבים סופיים. לממש פיקסל-פרפקט, בכפוף למערכת העיצוב הקיימת של המוצר (המוקאפ כבר מיושר אליה).

## עקרונות מוצר שאסור לשבור
- אין רגשות מומצאים ואין דירוג. מצבי תחנה נגזרים מהתנהגות בלבד: הושלם / כאן עכשיו / עצר כאן / עוד לא הגיע, + סיגנל פעיל.
- שתי שתיקות שונות: "נעלם" (לא נכנס) לעומת "נכנס ולא מתקדם" — השנייה דחופה יותר ומסומנת בצ'יפ "נכנסת — ולא מתקדמת" ליד "נראה לאחרונה".
- עברית, RTL מלא (`dir="rtl"`). הנתיב מתחיל מימין-למעלה ומתפתל שמאלה ומטה.
- "אתה כאן" חייב להיקרא תוך שנייה: הרכזת סורקת ~30 מסכים כאלה ביום.
- תחנת "עצר כאן" (⏸) — הבולטות הגבוהה ביותר אחרי סיגנל אדום, כולל משך העמידה ("12 ימים מול בחירת הכיוון").
- שלבים עתידיים קיימים אך שקטים (אפור חם, ללא צבע).

## מבנה המסע (12 תחנות, 6 שלבים)
1. **פתיחת חשבון** — נרשם/ה ומילא/ה שאלון בסיס
2. **היכרות** — פגישה 1 (נקבעה והתקיימה; משוב "היה טוב" / "לא הצלחתי" 🔴)
3. **טעימות הייטק** — טעימות תחומים (עד 6, עם שמות; פער SCCT = צ'יפ 💬 שיחה מחזקת)
4. **מסלול לימודים** — פגישה 2 → בחירת כיוון (מועדת ל-⏸) → שאלון אילוצים → רשימת מוסדות
5. **מלגות והרשמה** — פגישה 3 → בחירת מוסד + גיבוי → מלגות שנבחרו (התנגשות פתוחה = 🔴) → משימת העוגן: ההרשמה
6. **סטודנט/ית** — אישור לימודים הועלה ואומת

## Interactions & Behavior
- לחיצה על תחנה: toggle של פאנל הפירוט (תחנה פתוחה → נסגרת; אחרת נפתחת עם האירועים שלה). גם תחנות עתידיות לחיצות (מציגות "אין אירועים בתחנה זו עדיין").
- Hover על תחנה: `translateY(-2px)`.
- פעימת "כאן עכשיו": CSS keyframes, 2s infinite (ראו `tcPulse` בקובץ).
- מובייל/צר: המפה נגללת אופקית (קנבס 1000px), שאר הבלוקים נערמים.
- מצבי focus למקלדת: לממש לפי הדפוסים הקיימים בקודבייס (לא מומש במוקאפ).

## State Management
- `openStationId: string | null` — התחנה שפירוטה פתוח. אתחול: תחנת ה-stuck אם קיימת, אחרת null.
- דאטת המועמד מהשרת: פרטי פרסונה, מפת תחנה→{state, date, chips, events, action, stuckDays, signal}, רשימת ביקורים, רשימת סיגנלים פעילים. מצבי התחנות **נגזרים מאירועים** — אין שדה "רגש".
- דוגמאות דאטה מלאות בעברית לשני מועמדים (זורם / תקועה) — באובייקט `DATA` בקובץ.
