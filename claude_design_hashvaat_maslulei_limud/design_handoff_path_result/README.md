# Handoff: מסך "המסלול שמתאים לך" (Path Result — Step 4)

## Overview
מסך תוצאת ההמלצה בשלב 4 של אפליקציית Techcareerly (`/paths → result`). המשתמש סיים שאלון של 8 שאלות, ומנוע ניקוד משוקלל הפיק המלצה על אחד משלושה מסלולים: **תואר אקדמי · הכשרה טכנולוגית · הנדסאי (מה"ט)**. המסך מציג המלצה אחת מודגשת עם נימוק אישי שנבנה מהתשובות, ומאפשר השוואה מהירה ומכבדת מול שני המסלולים האחרים.

**הכיוון הנבחר: חלופה א' (1a) — רשת שוויונית עם כתר.** קובצי העיצוב כוללים גם את חלופות 1b ו-1c לעיון, אך היעד למימוש הוא 1a.

## About the Design Files
הקבצים בחבילה זו הם **רפרנסים עיצוביים שנבנו ב-HTML** — פרוטוטייפים שמראים מראה והתנהגות מכוונים, לא קוד production להעתקה ישירה. המשימה: **לממש מחדש את העיצוב בסביבת הקוד הקיימת של האפליקציה** (React/Vue/וכו') לפי הדפוסים והספריות שלה. אם אין עדיין סביבה — לבחור framework מתאים ולממש שם.

## Fidelity
**High-fidelity.** צבעים, טיפוגרפיה, ריווחים, רדיוסים והמיקרו-קופי סופיים. יש לשחזר פיקסל-פרפקט (בכפוף לרכיבי המערכת הקיימים). כל הטקסטים בעברית, **RTL מלא חובה**.

## עקרונות מוצר (קווים אדומים)
1. **זה לא מסך השוואה ניטרלי** — יש המלצה אחת מודגשת עם נימוק אישי מהמערכת. המוצר בעמדה: תואר עדיף כשאפשר. שני האחרים מוצגים בכבוד — לא מוקטנים, לא מוסתרים.
2. **בהירות > שלמות** — הקהל כולל דור ראשון להשכלה גבוהה; מסך עמוס נקרא "זה לא בשבילי". בדיוק 3 שורות השוואה, לא יותר.
3. **חסם תמיד עם מקטין** — שורת ✕ לעולם לא מופיעה בלי החלק שמקטין את החסם.
4. **אסור:** מספרי שכר התחלתי · אחוזי השמה · תוויות "קל/קשה" · הסתרת מסלול · קרוסלה שמסתירה כרטיסים במובייל בלי אינדיקציה.

### מובייל (390px), שני מסכים
1. **מסך פתיחה "שלושתם במסך אחד"**: header → נימוק אישי (קופסה `#ffffff`, border `#fdd9ae`, טקסט `#7a3c00` 13px) → **טבלת 3 עמודות** (grid, gap 7px): כל עמודה עם header צבעוני (מומלץ: רקע `#fb8500` טקסט לבן + "👑 ההמלצה"; אחרים: רקע `#eef3fb` טקסט `#023e8a`), אייקון, שם, משך, ואז 3 נתוני ליבה מקוצרים (⏳/💰/🚪, 11.5px). לחיצה על עמודה פותחת את הכרטיס המלא. מתחת: CTA ראשי `נמשיך עם {שם המסלול} ←` + CTA משני `להשוואה המלאה — כרטיס אחר כרטיס`.
2. **ערימה אנכית של הכרטיסים המלאים** — המומלץ ראשון.

### מבנה כרטיס (TrackCard) — זהה בשלושתם
מלמעלה למטה:
1. **פס כתר** (מומלץ בלבד): רקע `#fb8500`, טקסט לבן `👑 ההמלצה שלנו בשבילך` (12.5px, 800, padding 7px 16px).
2. **Header**: אייקון (24px emoji: 🎓/💻/⚙️) + שם (18px, 800, `#023e8a`) + שני תגים pill: משך (רקע `#eef3fb`, טקסט `#023e8a`) + אופי (outline `#d8dfe9`, טקסט `#3f4f63`) — 12px, 600.
3. **נימוק אישי** (מומלץ בלבד): קופסה רקע `#fff8ee`, border `1px #fdd9ae`, radius 12px, טקסט 13.5px/1.6 `#7a3c00`. **התוכן מגיע מהמערכת (template מהתשובות) — placeholder בעיצוב.**
4. **3 שורות השוואה קבועות** (אימוג'י 15px + label 11.5px 800 `#94908a` + ערך 13.5px `#1e2f42`).
5. **שורת אמת**: ✓ יתרון — רקע `#e8f6ef`, טקסט `#04543a`; ✕ חסם+מקטין — רקע `#fdeede`, טקסט `#8a4a09` (12.5px, radius 10px, padding 8px 11px).

7. **CTA**: מומלץ — כפתור מלא `#fb8500`, לבן, radius 14px, padding 13px, 15.5px 800, `נמשיך עם זה ←`, hover `#e07600`. אחרים — outline `1.5px #023e8a`, טקסט `#023e8a`, `להכיר את המסלול הזה`, hover רקע `#eef3fb`.

### שורת אמת + התאמה (מיקרו-קופי פרו-אקדמי מאושר)
**תואר:**
- ✓ מעלה משמעותית את הסיכוי להיכנס להייטק עצמו — לחברות הטכנולוגיה, ולא רק לתפקידים טכנולוגיים בבנקים וארגונים אחרים
- ✕ שלוש שנים בלי משכורת מלאה — אבל משרת סטודנט ומלגות סוגרות חלק גדול
- מתאים למי שיכול להשקיע עכשיו — זו ההשקעה שמחזירה הכי הרבה לאורך זמן

**הכשרה:**
- ✓ הדרך הקצרה ביותר למשרה ראשונה בהייטק
- ✕ התחרות על המשרה הראשונה אמיתית — אבל ליווי השמה ותיק עבודות טוב מקטינים את הפער
- מתאים למי שחייב להגיע מהר לשוק עכשיו — ותואר יכול לחכות ולהגיע אחר כך

**מה"ט:**
- ✓ ממשיכים לעבוד ולהתפרנס לאורך כל הלימודים
- ✕ מוכר פחות מתואר אקדמי אצל חלק מהמעסיקים — אבל אפשר להשלים ממנו לתואר בהמשך
- מתאים למי שחייב הכנסה שוטפת ומעדיף קצב יציב

### נימוק אישי (דוגמאות דמו — בפועל מגיע מהמערכת)
- המלצת תואר: "בגלל שאמרת שיש לך בגרות מלאה, שהזמן שלך פנוי יחסית ושחשוב לך אופק ארוך — תואר אקדמי הוא נקודת הפתיחה החזקה ביותר בשבילך, וזה בדיוק הרגע לנצל אותה."
- המלצת הכשרה: "בגלל שאמרת שיש לך ילדים קטנים ושחשוב לך להתחיל לעבוד מהר — הכשרה טכנולוגית ממוקדת היא הדרך הקצרה ביותר שלך למשרה ראשונה."

### קיצורים לטבלת המובייל

## Interactions & Behavior
- **CTA ראשי** `נמשיך עם זה ←` → ממשיך לשלב הבא (מסלולי כניסה, חסמים, מוסדות) עם המסלול המומלץ.
- **CTA משני** `להכיר את המסלול הזה` → עמוד/מצב פירוט של אותו מסלול. בחירה במסלול לא-מומלץ היא לגיטימית — בלי חיכוך או אישור נוסף.
- **מובייל, טבלת הפתיחה**: לחיצה על עמודה גוללת/מנווטת לכרטיס המלא של אותו מסלול.
- Hover: CTA ראשי מכהה ל-`#e07600`; משני מקבל רקע `#eef3fb`. Focus: מתאר נראה (לא ברירת מחדל של הדפדפן).
- אין אנימציות מעבר נדרשות; fade/slide עדין בכניסת המסך — לשיקול המפתח.

## State Management
- **קלט מהשרת/מנוע הניקוד**: `recommendedTrackId` (`degree|bootcamp|mahat`) + `personalReason` (string מוכן). כל שאר תוכן הכרטיסים סטטי.
- ההמלצה קובעת: איזה כרטיס מקבל כתר/מסגרת כתומה/נימוק/CTA ראשי; במובייל — סדר הערימה (מומלץ ראשון) ועמודה מודגשת בטבלה.
- אין state מקומי מעבר לניווט.
