# Handoff: רמה 3 — מוסדות ותוכניות של תואר נבחר (גישה 1a)

## Overview
מסך ניהול פנימי (מטה) של עמותה שמלווה צעירים יוצאי אתיופיה ללימודי הייטק. המשתמשים הם מנהל התוכנית ורכזות — לא מועמדים. דסקטופ, עברית, RTL, רוחב ~1100px, גלילה אנכית.

המסך ממפה שרשרת של שלוש רמות: **תחום ← תארים ← מוסדות ותוכניות**. רמות 1–2 כבר קיימות במוצר (ראו `existing-screen-levels-1-2.png`). ה-handoff הזה מגדיר את **רמה 3**: מה קורה כשלוחצים על תואר.

הגישה שנבחרה: **1a — פרישה בתוך הדף**. התואר נפתח במקום, מתחת לרשת התארים; התחומים והתארים נשארים גלויים מעליו. אין ניווט, אין פאנל, אין מסך נפרד.

המסך משרת **סימון**, לא רק צפייה: המנהל מסמן לכל תואר אילו מוסדות מומלצים, והסימון זורם לאפליקציית המועמדים.

## About the Design Files
הקבצים בחבילה הזאת הם **הפניות עיצוב שנכתבו ב-HTML** — פרוטוטייפים שמראים מראה והתנהגות מכוונים, לא קוד production להעתקה.
המשימה: **לשחזר את העיצוב בסביבה הקיימת של הקוד** (React + Tailwind, לפי הבקשה) עם הפטרנים והספריות שכבר קיימים בפרויקט. אם אין עדיין סביבה — לבחור את המתאימה ולממש שם.

- `level3-approaches.dc.html` — קובץ העיצוב. הוא מכיל שישה מוקאפים: סבב 2 (2a/2b/2c) בראש הקובץ וסבב 1 (1a/1b/1c) מתחתיו. **הרלוונטי למימוש הוא בלוק `id="1a"` בלבד**; שאר הבלוקים הם היסטוריית חלופות שנדחו — אפשר להתעלם מהם (או להשתמש ב-2a כרפרנס משני לחלוקה לשכבות).
- `support.js` — ריצת התצוגה של קובץ העיצוב בלבד. לא חלק מהמימוש.
- `existing-screen-levels-1-2.png` — צילום המסך הקיים; ממנו נגזרת שפת העיצוב (כרטיסים, פילים, צבעי תחומים).

לפתיחת קובץ העיצוב: לפתוח `level3-approaches.dc.html` בדפדפן (ליד `support.js`), ולגלול לסקציה עם התג `1a`.

## Fidelity
**High-fidelity.** צבעים, טיפוגרפיה, ריווח, רדיוסים ומצבי סימון סופיים — לשחזר פיקסל-פרפקט בעזרת Tailwind. הטקסטים במוקאפ הם הטקסטים הסופיים ל-UI (התוכן עצמו — שמות מוסדות ותוכניות — מגיע כ-props).

## Screen / View

### שם: פרישת רמה 3 (Degree Expansion Panel)
**מטרה:** רכזת בוחרת תואר, רואה את כל המוסדות שמלמדים אותו מסודרים לפי עוצמת הקשר עם העמותה, ומסמנת אילו מהם יומלצו למועמדים.

**מבנה מלמעלה למטה (בתוך מיכל בצבע קרם `#f5f3ef`, `border: 1px solid #ddd8cf`, `border-radius: 14px`, `padding: 22px`):**

1. **רצועת תחומים (רמה 1)** — `flex`, `gap: 8px`, 8 פילים תמיד גלויים. פיל: `padding: 8px 14px`, `border-radius: 9px`, `font-size: 13px`. תחום פעיל: רקע בצבע התחום המלא + טקסט לבן + `font-weight: 700`. תחום לא פעיל: רקע בהיר (~10% מצבע התחום) + טקסט בצבע התחום, `font-weight: 500`.
2. **רשת התארים (רמה 2)** — `grid-template-columns: repeat(4, 1fr)`, `gap: 12px`. כרטיס תואר לא נבחר: רקע לבן, `border: 1px solid #e4dfd6`, `border-radius: 12px`, `padding: 14px 16px`, `opacity: 0.6`. כרטיס נבחר: `border: 2px solid <צבע התחום>`, `border-radius: 12px 12px 0 0`, ללא גבול תחתון — הכרטיס מתמזג ויזואלית עם פאנל הפרישה שמתחתיו. זה החיבור החזותי המרכזי של הגישה.
3. **פאנל הפרישה** — רקע לבן, `border: 2px solid <צבע התחום>`, `border-radius: 0 0 12px 12px`, `padding: 20px 22px 22px`, `display:flex; flex-direction:column; gap:20px`. ארבע קבוצות, בסדר קבוע:

**קבוצה 1 — תוכניות פתוחות לתואר הזה**
כותרת קבוצה: `font-size:14px; font-weight:900; color:#023e8a`, לצידה מונה `#8a877f` וקו שיער `1px #eae5dc` שממלא את השארית.
שורה: `border:1px solid #cfe8e2; background:#f4fbf9; border-radius:10px; padding:12px 16px; display:flex; align-items:center; gap:16px`.
תוכן: `<b>שם המוסד</b> · שם התוכנית` בגודל 15px `#023e8a`; מתחת שורת פירוט 13px `#5c5a55` ("מלגה מלאה · קבלה חלופית · ליווי אישי — התוכנית מופה לתואר הזה"). בקצה — כפתור סימון.

**קבוצה 2 — ⚠️ תוכניות שלא אומתו לתואר הזה**
`border: 1px dashed #fb8500; background:#fff7ed; border-radius:10px; padding:14px 16px`.
כותרת: `⚠️ תוכניות שלא אומתו לתואר הזה — N`, `font-weight:900; color:#b45309`.
משפט הסבר 13px `#7c4a11`: "המוסד מלמד את התואר, אבל לא סומן לאילו תארים התוכנית פתוחה. לא ידוע שהיא פתוחה לתואר הזה, ולא ידוע שהיא סגורה."
שורה פנימית: רקע לבן, `border:1px solid #f5d8b3`, `border-radius:8px`; טקסט משנה "לא אומת לתואר הזה" ב-`#b45309`; כפתור משני "אמת מול המוסד" (`border:1px solid #fb8500; color:#b45309; background:#fff`).
הקבוצה מופיעה **בין** קבוצה 1 לקבוצה 3 — לא מוסתרת, ולא מוצגת כתוכנית פתוחה. אם אין סתירות — הקבוצה לא מוצגת כלל.

**קבוצה 3 — ★ קשר ישיר לעמותה — ללא תוכנית ייעודית**
שורות `border:1px solid #e4dfd6; border-radius:10px; padding:12px 16px`, כוכב ★ לפני השם, ואחריו `· ללא תוכנית ייעודית` ב-13px `#8a877f`.

**מוסד ששייך ליותר מקבוצה אחת (למשל תוכנית פתוחה *וגם* ★ קשר ישיר):** הקיבוץ נקבע לפי **הדלת החזקה ביותר** — המוסד מופיע פעם אחת בלבד, בקבוצה הגבוהה ביותר שהוא עומד בה (1 > 2 > 3 > 4). התכונות הנוספות לא נעלמות: הן מוצגות כתגים בשורה עצמה. תג ★ בשורה: `background:#eaf0f8; color:#023e8a; font-size:11px; font-weight:700; padding:2px 8px; border-radius:999px`, טקסט `★ קשר ישיר`, ממוקם `gap:8px` אחרי שם המוסד. שמות הקבוצות מנוסחים בהתאם — קבוצה 3 היא "קשר ישיר **ללא תוכנית ייעודית**", כדי שלא ייראה שמוסד חסר ממנה.
לוגיקה: `group = program?.openToDegreeIds.includes(degreeId) ? 1 : program && program.openToDegreeIds.length === 0 ? 2 : inst.hasDirectContact ? 3 : 4`, ובנפרד `badges = { directContact: inst.hasDirectContact, hasProgram: !!program }`.

**קבוצה 4 — מוסדות נוספים שמלמדים את התואר**
`grid-template-columns: repeat(2, 1fr)`, `gap: 8px`; שורות דחוסות יותר (`padding:10px 14px`, `border:1px solid #eae5dc`, טקסט `#3c3a36`).

**כפתור הסימון (בכל שורה):**
- לא מסומן: `background:#fff; border:1px solid #ddd8cf; color:#023e8a; font-weight:500`; טקסט "סמן כמומלץ".
- מסומן: `background:#059669; border:1px solid #059669; color:#fff; font-weight:700`; טקסט "✓ מסומן".
- משותף: `font-size:13px; padding:7px 13px; border-radius:8px; cursor:pointer; white-space:nowrap; align-self:flex-start`.

**כרטיס התואר הנבחר** מציג: `✦` אם מומלץ, שם התואר (16px, 700, `#023e8a`), תג רמת התואר (`B.Sc`, 12px `#8a877f`), שורת נתונים "38.7K ₪ שכר · 75% בטק" (אחוז ההגעה לטק ב-`#059669` bold), פיל רמת כניסה, ופיל מונה סימון.

**פילים (Pills):** `font-size:12px; padding:3px 9px; border-radius:999px`.
- כניסה נגישה: `bg #e6f4ef` / `#059669`
- כניסה בינונית: `bg #fdf1de` / `#b45309`
- כניסה תחרותית: `bg #fbeaea` / `#dc2626`
- "N מוסדות סומנו": `bg #e6f4ef` / `#059669`, bold
- "טרם סומן מוסד": ללא רקע, `#fb8500`, `font-weight:700` — **תמיד מוצג, אף פעם לא מוסתר**

## Interactions & Behavior
- לחיצה על **תחום** → פורשת את התארים שלו ברמה 2, סוגרת פרישת תואר פתוחה. כל 8 התחומים תמיד גלויים. תחום ללא תארים ממופים חייב להציג זאת במפורש ("אין תארים ממופים") — זה ממצא, לא באג.
- לחיצה על **תואר** → פותחת את פאנל רמה 3 מתחת לרשת התארים; לחיצה חוזרת סוגרת. תואר פתוח אחד בכל רגע (חשיפה הדרגתית — אף פעם לא כל הקשרים בבת אחת).
- כל מוסד מופיע **פעם אחת בלבד** בפאנל. חפיפות (תוכנית + ★) מוצגות כתגים בשורה, לא בשכפול השורה בשתי קבוצות.
- לחיצה על **כפתור סימון** → toggle מיידי (אופטימי), שמירה לשרת ברקע; בכישלון — חזרה למצב הקודם והודעת שגיאה inline.
- "אמת מול המוסד" → פותח משימת אימות (מחוץ ל-scope של המסך הזה; להשאיר כ-callback prop).
- מעברים: פתיחת פאנל ~180ms ease-out (גובה/אטימות). אין אנימציות אחרות.
- Hover: שורות מוסד — `box-shadow: 0 1px 4px rgba(2,62,138,0.08)`; כפתור לא מסומן — `border-color:#023e8a`.
- Focus: מסגרת `2px solid #fb8500` עם `outline-offset: 2px` — נדרש לניווט מקלדת של רכזות.
- מצב ריק: תואר בלי מוסדות ממופים → "טרם סומן מוסד לתואר הזה" בכתום `#fb8500`, במרכז הפאנל, לא כרטיס ריק.
- Responsive: המסך מיועד לדסקטופ ~1100px. מתחת ל-900px רשת התארים יורדת ל-2 עמודות וקבוצה 4 לעמודה אחת.

## State Management
- `selectedDomainId: string | null`
- `selectedDegreeId: string | null` (null = פאנל סגור)
- `markedByDegree: Record<degreeId, Set<institutionId>>` — מקור האמת לסימון; משתנה ב-toggle, נשמר לשרת.
- `savingIds: Set<string>` — שורות בשמירה (להשבתת כפתור).
- קיבוץ המוסדות (4 הקבוצות) הוא **נגזרת מחושבת** ולא state: לכל מוסד שמלמד את התואר —
  1. יש תוכנית שרשימת התארים שלה **כוללת** את התואר → קבוצה 1
  2. יש תוכנית שרשימת התארים שלה **ריקה / לא מופתה** → קבוצה 2 (סתירה). ריק = לא מופה, **לא** "הכל"
  3. אין תוכנית, אבל `hasDirectContact` → קבוצה 3
  4. אחרת → קבוצה 4

## Data (props)
הרכיב עצמאי; כל התוכן נכנס כ-props.

```ts
type Domain = { id: string; name: string; color: string; degreeIds: string[] };
type Degree = {
  id: string; name: string; level: string;          // "B.Sc" | "B.A"
  avgSalary: number; employedPct: number; techPct: number;
  entryLevel: 'accessible' | 'medium' | 'competitive';
  caveat: string;                                    // הסתייגות כנה, מוצגת כלשונה
  recommended: boolean;                              // ✦
  domainIds: string[];                               // >1 = תואר רחב
};
type Institution = { id: string; name: string; hasDirectContact: boolean; degreeIds: string[] };
type Program = {
  id: string; name: string; institutionId: string;
  openToDegreeIds: string[];                         // [] = לא מופה — לא "הכל"
  benefits: string[];
};
type Props = {
  domains: Domain[]; degrees: Degree[]; institutions: Institution[]; programs: Program[];
  marked: Record<string, string[]>;                  // degreeId -> institutionIds
  onToggleMark(degreeId: string, institutionId: string): void;
  onRequestVerification(programId: string, degreeId: string): void;
};
```

**כללי כנות (אילוצים קשיחים):**
1. נתון לא מאומת מסומן ככזה בכתום ובמילים. אין המצאות ואין השלמות.
2. `openToDegreeIds: []` פירושו "לא נבדק" — לעולם לא להסיק פתיחות ולעולם לא להסתיר את השורה.
3. סתירה (מוסד מלמד, התוכנית לא נבדקה) היא מידע — היא מוצגת במילים מלאות.
4. "טרם סומן מוסד" מוצג בכתום, לא מוסתר.

## Assets
אין תמונות. הסמלים הם תווי טקסט: `✦` (תואר מומלץ), `★` (קשר ישיר), `⚠️` (לא אומת), `✓` (מסומן). אם הפרויקט משתמש בספריית אייקונים — להחליף את ⚠️ ו-✓ בלבד; ✦ ו-★ לשמור כטקסט.
